Hub Announcement Counter

The announcement goes out as up to two embeds in one post. Fill the first box, then put the rest in the second. Counts update as you type and match how Discord measures. Your text stays in this browser between visits.

How this is counted
  • The whole post can hold 6,000 characters. The title, the footer and the opt-out notice already use 216 of them, which leaves 5,784 for your two boxes together.
  • Each embed holds at most 4,096. Once the first box is full, the second can take 1,688.
  • Everything counts: spaces, line breaks, and markdown like **, ## and >.
  • Most emoji count as 2, because that is how Discord counts them. 📢 is 2, and so is 💫.
  • Copy both puts a line of ===== between the boxes, so it's clear where the second embed starts.
